# Kevin & Tess Rental Dashboard

A mobile-friendly rental comparison dashboard tailored to Kevin and Tess.

## Features

- Ten ranked two-bedroom rental options
- Detailed top-five cards with listing photography
- Simpler backup cards for ranks six to ten
- EPC, council-tax, parking and outdoor-space indicators
- Estimated rent and monthly bills
- 50/50 or income-based split calculations
- Estimated money left after housing
- Filters for garden/outdoor space, two-car suitability and Guildford location
- Saved-property buttons using browser local storage

## Open locally

Open `index.html` in a modern browser.

## Publishing

The repository is private because the dashboard contains approximate income and insurance information. GitHub Pages availability for private repositories depends on the account plan and repository settings.

## Updating properties

Edit the `homes` array near the bottom of `index.html`, then commit the updated file.

## Important

Rental availability, prices and portal image URLs change quickly. Reconfirm every listing, EPC, council-tax band, parking arrangement and bill estimate before paying a holding deposit.
